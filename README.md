# my-service

교육과정 운영을 돕는 작은 연습용 화면 모음입니다.

## 교육 배정현황 (`index.html`)

`02_instructors.csv`의 내용을 카드 형태로 보여주는 한 장짜리 화면입니다.

- 카드 하나에 교육(모듈) 한 건 — 교육명, 강사, 보조강사, 일정, 장소
- 강사·보조강사 옆의 상태 배지(확정 / 회신 대기 / 강의안 대기 / 일정 조율 중 / 보류)는 눌러서 바꿀 수 있습니다
- 왼쪽 아바타는 외부 이미지 없이 SVG로 그린 픽셀 캐릭터입니다

### 보는 방법

`index.html` 파일을 브라우저로 열면 됩니다. 별도 설치나 서버가 필요 없습니다.

명단을 바꾸려면 `index.html` 안의 `ROWS` 배열을 수정하세요.
화면에서 바꾼 상태는 저장되지 않고, 새로고침하면 처음 값으로 돌아옵니다.

> 담겨 있는 데이터는 실제 자료가 아닌 예시입니다.
