# my-service

교육과정 운영을 돕는 작은 연습용 화면 모음입니다.

## 강사 메일 답장 도우미 (`index.html`)

강사님을 고르면 그분과 주고받은 메일이 말풍선으로 보이고,
그 자리에서 답장 초안까지 만들어주는 한 장짜리 화면입니다.

- 왼쪽 — 강사님 목록 16줄 (강사 8 + 보조강사 8). 한 줄에 픽셀 캐릭터 아바타 + 성함 + 상태
- 오른쪽 위 — 고른 강사님의 아바타·성함·맡으신 모듈과 일정 한 줄
- 오른쪽 가운데 — 주고받은 메일을 오래된 것부터 말풍선으로. 강사님은 왼쪽(아바타 붙음), 우리 메일은 오른쪽 연파랑. 말풍선마다 날짜를 작게 표시
- 오른쪽 아래 — 「답장 초안 만들기」 버튼 하나. 지금은 미리 넣어둔 예시 문장이 뜹니다

기획서는 [spec.md](spec.md), 결과 모양만 담은 예시 화면은 `example.html`에 있습니다.

### 보는 방법

**내 컴퓨터에서 확인할 때**

```
node dev-server.js
```

를 실행하고 브라우저에서 <http://localhost:3000> 을 엽니다.
(`index.html` 파일을 그냥 두 번 눌러 열면 AI 호출이 되지 않습니다. 주소로 열어야 합니다.)

**Vercel에 올렸을 때**

그대로 돕니다. 단, Vercel 프로젝트 설정의
`Settings → Environment Variables` 에 `GEMINI_API_KEY` 를 등록해야 합니다.
(`.env` 파일은 깃허브에 올라가지 않으므로 Vercel이 알지 못합니다.)

명단은 `index.html` 안의 `ROWS`, 메일 이력은 `MAILS`를 고치면 바뀝니다.
초안은 저장되지 않고, 새로고침하면 사라집니다.

> 담겨 있는 강사 명단과 메일 내용은 실제 자료가 아닌 지어낸 예시입니다.
